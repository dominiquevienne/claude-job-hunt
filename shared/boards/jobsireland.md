# Board adapter — JobsIreland (Ireland)

<!-- hosts: jobsireland.ie -->
<!-- script: jobsireland.py -->
<!-- countries: IE -->

**4 934 live ads** from Ireland's public employment service, run by the
Department of Social Protection. The **fifth national public employment
service** here after `job-room.md` (CH), `france-travail.md` (FR),
`empleate.md` (ES) and `arbeitsagentur.md` (DE), and **the first Irish
adapter**.

**Everything here was verified against the live site on 2026-09-01.**

**The most useful thing this board taught is not the board.** See trap 1.

## Access

```
GET /robots.txt                                  → three lines, no Disallow
GET /Jobsireland.API/JobsIreland/BrowseJobs      → the ads, as an HTML fragment
     ?page=1&pageSize=100&location=&keyWord=
GET /en-US/job-Details?id=<id>                   → the ad, for a human
```

**No browser, no account, no key.** `robots.txt` is:

```
# robots.txt generated by Yaplex.SEO
User-agent: *
Sitemap: https://jobsireland.ie/sitemap.xml
```

**No `Disallow` line at all** — the most permissive file in this repository.
No crawler and no AI agent is named.

*(The sitemap it declares carries 107 content pages and **no vacancies**. The
ads are behind the endpoint above, which is why this adapter reads that instead
of the sitemap the file points at.)*

**The parameter names are not guessed.** They are read out of the page's own
`$.ajax` call: `keyWord`, `location`, `page`, `pageSize`, `CareerlevelId`,
`VacancyTypeId`, `ContractTypeId`, `NaceCode`, `RemoteOrBlendedJobType`.

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/skills/job-scan/scripts/jobsireland.py" \
  search --location Dublin --kind job
```

The response is an **HTML fragment**, not JSON — a server-rendered partial the
page drops into its results div. `pageSize` is honoured to at least 250; 1 000
works and returns 4.5 MB, 5 000 times out.

## Configuration

```yaml
boards:
  jobsireland:
    enabled: true
    searches:
      - { location: "Dublin", kind: "job" }
      - { location: "Cork", kind: "job" }
```

| Key | Required | Notes |
| :-- | :-- | :-- |
| `enabled` | yes | False or absent → not scanned |
| `location` | recommended | Free text, server-side — `Dublin` is 1 209 of 4 934 |
| `keyword` | no | Free text in the title |
| `kind` | **read the note** | `job`, `ces` or `wpep`. **`job` is the only one that is ordinary employment** |

## Traps

**1. The card's CSS class changes with the ad type, so splitting on the class
you see first silently selects one population.**

```
<div class="job-heading scheme-box"    …>   135
<div class="job-heading position-box"  …>   106
<div class="job-heading yess-box"      …>     9
<div class="job-heading #boxclass"     …>     1
```

`scheme-box` is the first variant that appears in the response. Anchor on it —
which is what anyone writing this parser from the first card they see will do —
and you get **136 of 251 cards, of which 135 are CES**.

**That is not a truncation you would notice.** It is a full-looking result set,
correctly parsed, every field populated. What it costs is not completeness but
*representativeness*: you would conclude that Ireland's public employment
service publishes nothing but state placement schemes.

The anchor is `job-heading `, the common prefix. And because a correct-looking
parse is exactly what this failure produces, the parse is **checked against the
number of ad links in the same document** — `job-Details?id=` — and fewer cards
than links is a hard error. That is issue #55's invariant carried from XML to
HTML: *look inside the response you already have for a quantity that could not
be what it is if your reading were right.*

**2. Some responses carry an uninterpolated template row.**

The fourth class, `#boxclass`, is a template that reached production. Its
fields are the literal strings `#JobReference`, `#StartDate`, `#EndDate`,
`#VacancyTypeId`.

**It is intermittent.** Measured across a `pageSize=100` sweep:

| Page | 1 | 2 | 5 | 20 | 45 | 49 |
| :-- | --: | --: | --: | --: | --: | --: |
| Cards returned | 100 | 100 | **101** | **101** | **101** | 100 |

Emitted unfiltered it becomes an ad published on `#StartDate`, and **a
spot-check of the first page would never see it**. Same species as the
`#{company.slug}` template a sibling session measured on trampos.co — a
placeholder that reads as data — with the intermittence of the
`Content-Encoding` flap on `infoempleo.md`.

Every field whose value starts with `#` is refused, so the row is dropped
whether or not its class gives it away.

## More than half of this board is not a job

| Reference | Class | `VacancyTypeId` | Of the 250 newest | What it is |
| :-- | :-- | --: | --: | :-- |
| `#JOB` | `position-box` | 0 | **106** | An ordinary paid vacancy |
| `#CES` | `scheme-box` | 3 | **135** | **Community Employment Scheme** |
| `#WPEP` | `yess-box` | 10 | 9 | Work Placement Experience Programme |

**CES is a state work-placement scheme**, not employment: part-time supervised
placement for long-term unemployed people, paid on a social-welfare rate, and
entered through an Intreo office rather than by applying to an employer. WPEP
is a placement too.

Nothing on the card says so in words — the distinction lives in a CSS class, a
reference prefix and a numeric id. So `offer_kind` carries it on every card
with a sentence explaining it, every run prints the split, and a run whose
result is majority-CES says so out loud.

**And the mix moves with the page.** The board is sorted newest first, and the
ordinary-job share ran **58, 33, 33, 48, 0 and 0 percent** on pages 1, 2, 5,
20, 45 and 49 of a `pageSize=100` sweep — page 45 was 99 scheme rows out of
100. A shallow sweep over-samples real jobs; a deep one under-samples them.
**Neither number is the board**, and any single figure quoted for "the CES
share" is a figure about a page.

## What the record carries

Measured on 251 cards from one `pageSize=250` response.

| Field | Coverage | Note |
| :-- | --: | :-- |
| `JobId`, `JobReference`, `JobTitle` | 251/251 | |
| `Location` | 251/251 | A full address |
| **Eircode** | **195/251** | A real postcode — `infoempleo.md` and `hays-fr.md` have none |
| `StartDate` (published) | 251/251 | Real and per ad: page 1 is today, page 45 is five weeks back |
| `EndDate` (closes) | 251/251 | Spanning the next eight weeks, **none already past** |
| Employer | **159/251** | From the logo's `alt`, `"Logo of …"` |
| `PAID POSITION` badge | 106/251 | Exactly the `#JOB` rows |

**The employer's coverage depends on which population you drew**: 89 of 106 on
ordinary jobs, **61 of 135** on CES rows, 9 of 9 on WPEP. Quoting 159/251 as
"the board names the employer 63% of the time" hides that a real vacancy names
it 84% of the time and a scheme row 45%.

There is no salary anywhere on the listing, and no description — the card is
title, employer, address, and two dates.

## Why Ireland, and what the search for a target found

The criteria were the ones that picked Germany: a country with **no adapter
written for it** in the coverage atlas, a real market, and a sanctioned door.
Ireland fails the second — 2.7 M workers, 10 entries to build, 16th on the
list — and was chosen because **the five larger candidates are all closed**,
each by a different mechanism, measured on 2026-09-01:

| Country | Rank | What was measured |
| :-- | :-- | :-- |
| Portugal | 1st, 19 to build | `netemprego.gov.pt` no longer resolves; `iefponline` redirects |
| Italy | 2nd, 18 | **Cliclavoro is no longer a board** — a news portal with zero vacancies |
| United Kingdom | 3rd, 17 | *Find a job* serves a **WAF failover page as HTTP 200**, even on `robots.txt` |
| Netherlands | 4th, 14 | `werk.nl` redirects everything to an Oracle SSO login |
| Poland | 7th, 12 | The portal sits behind F5 Shape anti-bot |

*(Three more were closed the same way while looking for the board after Sweden
— Norway, Finland and Denmark. All eight, with the exact mechanism for each and
what separates "inaccessible" from "refused" from "not sanctioned", are in
`shared/boards/README.md` § **Investigated and closed — eight national public
employment services**, which is where to look before probing a country.)*

**The national-public-service pattern that worked four times does not
generalise.** That is worth writing down: it was the highest-yield heuristic in
this repository and it has a hit rate, not a guarantee.

*(Two things found on the way. `cliclavoro.gov.it` refuses `ClaudeBot`, does
**not** name `Claude-User`, and sets `Content-Signal: search=yes, ai-train=no,
use=reference` on its `*` group — a European state using Content-Signal, and a
gradation case for issue #48. And Adzuna, which `shared/robots-policy.md`
already names as publishing a sanctioned API, covers **four of these eight** —
Italy, the United Kingdom, the Netherlands and Poland — and **not** Portugal,
Denmark, Finland or Norway. **Nor Ireland**, which is the country this file is
about: the `country` enum of its live OpenAPI, read 2026-09-02, is the 19
`gb us at au be br ca ch de es fr in it mx nl nz pl sg za` and nothing else. An
earlier draft of this parenthesis said "a dozen of these countries at once";
that was a guess, and the measured figure is four. Its key still needs an
account this plugin cannot open on the user's behalf, so it stays unbuilt rather
than unverified.)*

**Ireland now has a second board, and it is not a public service.**
`irishjobs.ie` turned out to be the StepStone platform — `siteId` 301 on the
same bundle as Totaljobs — so `stepstone.md` covers it, alongside `jobs.ie`
(`siteId` 302) and `nijobs.com`, which serve **the same inventory**: an id from
any of the three resolves on the other two, and none of them resolves on
Totaljobs. Three domains, one Irish board; enable one.
The two Irish boards are complementary rather than redundant: this one is the
state's, where more than half the rows are placement schemes and there is no
salary at all; IrishJobs is the private market, which names a salary figure on
**27 of 100** cards and says `€ Not Disclosed` on the other 73. Neither one is
Ireland on its own.

## Verification

```bash
S=skills/job-scan/scripts/jobsireland.py
python3 $S count                              # 4 934
python3 $S count --location Dublin            # 1 209
python3 $S search --location Dublin --kind job --limit 100
python3 $S search --limit 250 --page-size 100 # prints the kind split
```

The parse guard is the one to re-check after any change, because its failure
mode is a complete-looking result set:

```python
parse(doc_with_5_links_and_no_matching_cards)   # → must die, not return []
field('<input id="StartDate" value="#StartDate" />', 'StartDate')   # → None
```
